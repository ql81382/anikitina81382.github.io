In this assignment, I learned more about computer networking and how different devices communicate through the Internet. I reviewed information about Internet reference models, protocols, and the Domain Name System (DNS). Before this lesson, I knew how to connect my computer to Wi-Fi, but I did not understand everything that happens behind the connection. I learned that IP addresses help identify devices on a network and that DNS translates website names into IP addresses. This information is useful because I use the Internet every day for college assignments, communication, and work.

Another important part of this lesson was learning about network settings and how to check Internet connectivity. I learned about the Windows Command Prompt and commands such as ipconfig, ping, tracert, and nslookup. These tools help identify network information and troubleshoot connection problems. For example, ipconfig displays IP address information, while ping helps check whether a device can communicate with another device or server. I also learned that tracert shows the path information takes across a network. Understanding these commands will help me identify possible connection problems instead of immediately asking someone else for technical assistance.

I also learned about sharing folders between computers connected to the same network. This can be helpful when people need to access the same documents without sending them through email. In my transportation job, sharing information is important because dispatchers and other employees need access to documents and updates. I also reviewed differences between Windows, macOS, and Linux, including their licensing and support costs. Another interesting topic was comparing Internet providers and connection types, such as cable, DSL, cellular, and satellite. I learned to compare Internet service based on speed, reliability, availability, security, and cost.

Finally, I learned about the basic equipment needed to create a home network. A modem, router, network cables, and wireless devices all have different purposes. A router lets multiple devices share an Internet connection, while Wi-Fi lets you connect without cables. This is especially useful in my home because several devices may need Internet access at the same time. Overall, this assignment helped me understand how computer networks work and why reliable Internet connections are important. I believe this knowledge will be useful for my future studies in Graphic Arts and Web Design, my work, and everyday computer use.
