In this assignment, I completed several activities about search engines and learned better ways to find information on the Internet. The activities helped me understand that searching is more than just typing words into Google. I learned how different search engines work, how to use search operators, and how to decide whether online information is reliable. These skills will be useful for my college classes, especially when I need to research topics for assignments.

For the first activity, I learned about different search engines and how to search more effectively. I compared search results from Google, Bing, Yahoo, and Ask. I noticed that results and how information is displayed can differ between search engines. I also learned about keywords and how choosing better words can help me find information faster. I can use this skill for my school research because I often need to find reliable articles and information for assignments. Instead of using the first result I see, I can try different search engines and compare the information. This can help me find more useful sources and understand different ways information is presented online.

For the second activity, I practiced using search operators and exact phrases. I learned that quotation marks can make a search more specific because the search engine looks for the exact words together. Learning different search techniques can help when I need information from reliable sources, such as educational or government websites. I can use these search methods for research papers and other college assignments. Using specific search terms saves me time and makes it easier to find information directly related to my topic.

In the third activity, I learned how to evaluate search results and consider whether a source is trustworthy. I learned to check the author, organization, date, and purpose of a website before using the information. I also explored search engine optimization, or SEO, and learned that SEO helps websites become more visible in search results. This was especially interesting to me because I am studying Graphic Art and Web Design. Understanding SEO will be useful when I create websites in the future because good design and useful content should also be easy to find. I also learned that AI tools can help with finding and working with information, but the information should still be checked carefully for accuracy.
