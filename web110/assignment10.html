Assignment 10 - CSS

In this assignment, I learned how to use Cascading Style Sheets (CSS) to improve the appearance of web pages. Before completing this lesson, I knew how to create basic HTML pages, but I did not fully understand how to control their design. CSS allows me to change colors, fonts, text alignment, spacing, and backgrounds. I learned that HTML creates the structure of a website, while CSS controls how the website looks.

The first activity was creating an external CSS file named style.css. I added selectors for the body, headings, and paragraphs. I practiced using different CSS properties, including background-color, color, font-family, font-size, margin, padding, and text-align. After creating the stylesheet, I connected it to my HTML files. I learned that an external stylesheet is useful because I can make changes in one file instead of editing every web page separately.

The second activity was creating assignment10.html and practicing internal CSS. I added a style section in the HTML head and changed the heading's color and size. This helped me understand how internal CSS can override external CSS rules. I also learned that internal CSS is useful when I want to make a specific page look different from the rest of the website.

The third activity was practicing inline CSS. I added styling directly to a paragraph element and changed its text color, font size, background color, and padding. This activity helped me understand the difference between external, internal, and inline CSS. I also learned that inline CSS can override other styles when they apply to the same element.

Finally, I practiced checking my HTML and CSS code for errors and learned how to use Visual Studio Code to manage website files. These skills are important for my future career in graphic design and web design. I can use CSS to create attractive, organized, and user-friendly websites. I also plan to apply this knowledge to my personal website and future business website projects.
