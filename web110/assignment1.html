One topic I learned about was IP addresses. I had heard the term IP address before, but I did not really understand how important it is for communication between computers and networks. I learned that an IP address works like an identifier that helps send information to the correct device or destination. This made me think about how much communication happens in the background every time I use the internet. It was interesting to realize that when I visit a website, my computer needs to communicate with other devices using network addresses. I can see myself using this knowledge in my current work environment, especially because I work with computers and online systems every day. Even though I am not a network technician, understanding basic networking terms will make me feel more confident when I have to deal with technical problems or communicate with IT support. Another topic I learned about was traceroute and how it can help identify problems with an internet connection. Learning about traceroute made me realize that information actually travels through a long path before reaching a website. The data can pass through several different routers along the way. I also learned that traceroute can show how long it takes for information to travel between these points. I think this knowledge could be very useful because if I have a connection problem at work or in the future, I will better understand what might be happening instead of simply assuming my computer is the problem. The new topic I learned about, Git and Git repositories. I learned that Git is a version control system that tracks changes made to files and projects. One thing I liked about Git is that it allows you to keep a history of your work and return to an earlier version if something goes wrong. I also learned that a Git repository is where a project and its files are stored, while Git keeps track of the changes. Learning about GitHub and Bitbucket helped me understand how repositories can be stored online and shared with other people. I think this knowledge will be useful to me in the future, especially if I work on websites or other technology projects.
