First, we learned more about web browsers, their different kinds, and understood their main features and settings. A web browser is an application software that lets us view and explore information on the web by retrieving, displaying, and navigating content on the World Wide Web. In this class, I learned more about important browser functions such as tabs, bookmarks, the address bar, search tools, refresh buttons, and browser history. These features make it easier to find information and organize online work. This knowledge applies to my current school environment because I use web browsers every day to access Blackboard, research information, complete assignments, and communicate online. In the future, as a graphic and web design professional, I will also need to use different browsers to view and test websites. The second activity focused on browser settings and customization. I learned more about changing settings to make my Internet experience more convenient, secure, and suited to my needs. This knowledge is important because browser settings can affect privacy, security, appearance, cookies, and other browsing features.  Understanding these options is also important because browser settings can influence how websites work and how personal information is handled. I can apply this knowledge by reviewing my browser settings regularly and choosing options that balance convenience and privacy. This will also be useful in my future web design work because understanding browser settings can help me troubleshoot website problems and understand how users experience websites. In the third activity, we practiced with browser extensions and add-ons. I learned that extensions are software components that add features or improve a browser's functionality. Examples include grammar checkers, password managers, ad blockers, and other tools that can make browsing more efficient. I also learned that extensions should be selected carefully because they can have access to information and activity within the browser. This is especially important for privacy and security. I can apply this knowledge to my schoolwork by using useful extensions for writing, research, and organization. As a future graphic and web designer, I can also use browser extensions to support productivity, testing, accessibility, and web development. Overall, these activities helped me understand that a web browser is not just a tool for viewing websites but an important part of working effectively and safely online.
