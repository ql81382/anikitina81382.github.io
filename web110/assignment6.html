In this activity, I learned about the File Transfer Protocol (FTP) and how it transfers files between a client and a server over a network. I learned that FTP can upload and download files, but standard FTP doesn't always protect information because it can send authentication in clear text. I also learned about secure file transfer methods such as FTPS and SFTP. FTPS uses SSL/TLS, while SFTP uses SSH to help protect the communication. This information is useful to me because I work with digital files and study web design. In the future, I may need to upload website files or transfer files to a server. Understanding secure file transfer will help me choose safer ways to move files online.

In the second activity, I learned about peer-to-peer (P2P) networks. P2P technology lets computers communicate and share files directly with other computers instead of relying on a central distribution server. I learned that P2P networks can serve legitimate purposes, but they can also be used to share copyrighted material without permission. This activity helped me understand that technology itself is not necessarily good or bad; it depends on how people use it. I can apply this knowledge when sharing files online by making sure I have permission to share the content. It also reminds me to be careful about downloading files from unknown sources because they may contain security risks.

In this activity, I learned about Voice over Internet Protocol (VoIP) and remote desktop software. VoIP allows voice communications and multimedia sessions over Internet Protocol networks. Remote desktop software allows a person to control or access another computer from a different location. For example, the local computer can send mouse and keyboard inputs to the remote computer. These technologies are useful in everyday life and in the workplace. I can use VoIP to communicate with coworkers or others when working remotely. Remote desktop technology could also be useful if I need to access my files or help troubleshoot a computer from another location. Learning about these communication tools helped me better understand how people can work and communicate through the Internet.

Overall, these activities helped me understand several important Internet communication technologies. I learned how files can be transferred, how computers can share information through P2P networks, and how people can communicate or access computers remotely. These skills are useful for my future studies in graphic arts and web design.
