Assignment 8 - Internet Security

In this assignment, I learned about internet security and why protecting personal information online matters. The first activity introduced online threats such as viruses, malware, phishing, and identity theft. I learned that hackers can use fake emails, websites, and suspicious links to steal personal information. This information is useful because I use the internet every day for school, work, shopping, and communication. I understand that I need to be careful when opening emails, downloading files, and entering personal information online.

The second activity focused on web browser security. I learned how to check browser settings, updates, extensions, browsing history, and cookies. Keeping a browser updated is important because updates can fix security problems. I also learned about private browsing and how it can help prevent a device from saving browsing history. Another important topic was website security certificates and HTTPS connections. I learned that HTTPS helps protect information sent between a browser and a website. These security settings are useful when I access my college website, email, or online accounts.

The third activity introduced antivirus and anti-malware software. I learned that these programs help detect and remove harmful software from computers. I also learned about the EICAR test file, a harmless file used to check whether antivirus software can recognize a simulated threat. Regular security scans and software updates can help keep a computer protected. This is especially important because I use my computer for school assignments and work-related documents.

The fourth activity focused on password managers and multi-factor authentication. I learned that using strong, unique passwords for every account is a key part of internet security. Password managers help organize passwords without requiring you to remember them all. Multi-factor authentication adds another layer of protection by requiring additional verification. I think this is very useful for protecting my email, banking, and school accounts.

The final activity introduced firewalls and how they protect computers from unwanted network connections. I learned that a firewall monitors network traffic and helps block suspicious activity. This assignment helped me understand that internet security involves many different tools and personal habits. I can apply this knowledge in my everyday life by keeping software updated, using stronger passwords, avoiding suspicious links, and protecting my personal information.
